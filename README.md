
# ScentVault – Fragrance Collection Management Application

## Project Description

ScentVault is a fragrance collection management application that allows users to organize and keep track of the fragrances they own.

Users can save information about their fragrances, including the name, brand, fragrance type, notes, season, and occasion.

## Sprint 1 Goal

Allow a fragrance collector to add fragrances to their personal collection and view their saved fragrances in a collection list.

## Sprint 1 Features

- Add fragrances to a personal collection.
- Enter fragrance information.
- Save fragrance records.
- View saved fragrances in a collection list.

## Technologies Used

- HTML
- CSS
- JavaScript
- Browser Local Storage (planned)

## Project Structure

- index.html – Main application page.
- style.css – Application styling.
- script.js – Application functionality.
- README.md – Project description and instructions.
- .gitignore – Files excluded from Git.

## How to Run the Application

1. Download or clone the ScentVault repository.
2. Open the ScentVault project folder.
3. Open index.html in a web browser.
4. The application will run locally in your browser.

Alternatively, open the project in Visual Studio Code and use the Live Server extension.

## Sprint Information

Sprint 1 focuses on allowing users to add fragrances and view their saved collection.
